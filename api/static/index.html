¿A quién se le envía este reporte?

El reporte se envía automáticamente según la frecuencia elegida. Podés revisar el contenido exacto antes de programarlo.

Este servicio no tiene servidor de correo configurado, así que no puede enviar: se puede revisar el correo exacto que saldría, pero el envío requiere configurar REPORTE_SMTP_HOST en el servicio.

El envío programado lo ejecuta un proceso en el servidor. Las credenciales del servidor de correo se configuran como variables de entorno del servicio — nunca se piden desde esta pantalla.
